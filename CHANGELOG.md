# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [Unreleased]

## [1.0.0-rc.1] - 2026-08-30

### Changed

- Improvement to the way files are display to the users in the GUI.

### Fixed

- Fix typo in the License file.
- Fix Markdown indentation and grammar errors in the readme file.

## [1.0.0-rc.0] - 2026-07-19

### Added

- Add entry point for simpler execution.

## [0.5.1] - 2026-07-16

### Fixed

- Add pillow library to fix images compression error.

## [0.5.0] - 2026-07-16

### Added

- Add PDF Content Streams compression function.
- Add PDF image quality compression function.

## [0.4.1] - 2026-07-06

### Fixed

- Fix favicon path.

## [0.4.0] - 2026-07-06

### Added

- Add Favicon to the GUI.

## [0.3.0] - 2026-07-06

### Added

- Add exit menu button.

## [0.2.0] - 2026-07-06

### Added

- Add the option of adding files.
- Add the option to merge PDF.
- Add option to clear files.

## [0.1.0] - 2026-07-06

Creates the first version of the GUI for user to interact with
PDF files.

### Added

- Add the GUI for users interaction.
